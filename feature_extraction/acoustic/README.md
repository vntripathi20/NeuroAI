# feature_extraction/acoustic/

Planned home for acoustic feature extraction code: pitch, pitch variability,
MFCCs, jitter, shimmer, speech rate, pause statistics, and spectral
characteristics.

No extraction code exists yet — feature definitions and the specific
libraries used (e.g. `librosa`, `parselmouth`) will be chosen and documented
when this module is implemented, with citations to the acoustic-phonetics
literature justifying each feature's relevance to the conditions studied.
