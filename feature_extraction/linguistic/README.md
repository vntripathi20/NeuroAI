# feature_extraction/linguistic/

Planned home for linguistic feature extraction code: vocabulary diversity,
sentence structure/syntactic complexity, repetition, lexical
characteristics, and semantic characteristics derived from speech
transcripts.

No extraction code exists yet — the specific metrics and NLP tooling (e.g.
`spaCy`, `nltk`) will be chosen and documented when this module is
implemented, with citations justifying each feature's relevance.
